- **Category:** Linux Server Management & Web Hosting Control Panel
- **Operating Systems Supported:** Ubuntu Linux (20.04, 22.04, 24.04), AlmaLinux (8, 9), RHEL
- **Key Modules:**
  - Web Server: Nginx high-performance engine
