SecureMail: System Design & Architecture Overview
Cloud-Based Email Management System with Wire-Level Encryption & Anti-Spoofing
MCA-269 Minor Project
🛡️ 1. Defense-in-Depth Pipeline Architecture
Port 587 (Submission) & Port 25 (Relay) Step 1: Socket TLS 1.3
▼
Postfix Ingestion Gateway (Rate limiting & socket termination) Step 2: Postfix MTA
▼
Milter Stream Processor (2048-bit DKIM + SPF + DMARC p=reject) Step 3: Identity Verification
▼
In-Memory Privacy Sanitizer (1x1 & 0x0 Spy Pixel Purge in RAM) Step 4: Privacy Cleansing
▼
Dovecot LMTP Delivery (Maildir single-file mailbox storage) Step 5: Maildir Storage
▼
SHA-256 Merkle Audit Ledger (Tamper-evident chained hashing) Step 6: Forensic Audit
🗄️ 2. Database Schema & Entity Relationships (ERD)
Table / EntityPrimary KeyAttributes / Foreign KeysPurpose
USER_ACCOUNT user_id (INT) email_address (UQ), password_hash, role, created_at Campus authentication & roles
MAIL_MESSAGE message_id (INT) sender_id, recipient_id, subject, tls_cipher, dkim_verdict, sent_at Encrypted message metadata
AUDIT_BLOCK block_id (INT) message_id, event_type, prev_hash, current_hash, mined_at SHA-256 Merkle hash chain
MAILBOX_FOLDER folder_id (INT) user_id, folder_name (Inbox/Sent/Trash), unread_count Dovecot Maildir sync index
Relational Rules: USER_ACCOUNT (1) ➔ (N) MAIL_MESSAGE [sends/receives] ➔ (1) AUDIT_BLOCK [hashes event into Merkle chain].
👥 3. System Use Case & Actor Model
Student / Faculty Member:
• Login with Credentials • Compose Encrypted Email • Read Sanitized Inbound Mail • Inspect Security Badges (TLS 1.3 / DKIM)
Departmental Administrative Staff:
• Dispatch Examination Circulars • Distribute Verified Offer Letters • Broadcast Announcements with 2048-bit DKIM
System & Mail Administrator:
• Supervise Postfix/Dovecot Daemons • Manage Mailbox Quotas • Verify SHA-256 Merkle Audit Ledger • Configure Anti-Spoofing Policies
🔄 4. Data Flow Architecture (DFD Level-0 & Level-1)
[User / Sender] ➔ (1.0 Transport Layer Verification)
    ↓ (Encrypted Socket Stream)
    ➔ (2.0 Anti-Spoofing & Milter Gateway)
        ├─ [Spoofed/Cleartext] ➔ Drop Packet & Return SMTP 550
        └─ [Clean Stream] ➔ (3.0 In-Memory HTML Sanitizer)
                ├─ Strip 1x1 Spy Pixels in RAM
                ├─ ➔ (4.0 Maildir DB Storage) ➔ Recipient Inbox
                └─ ➔ (5.0 Merkle Ledger DB) ➔ SHA-256 Block Mine
