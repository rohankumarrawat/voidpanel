Where to get your WhatsApp Access Token & Phone Number ID?
1. Meta Developer Console: Open developers.facebook.com → My Apps → WhatsApp → API Setup.
2. Phone Number ID: Copy the number displayed in "Step 1: Phone number ID".
3. Permanent Access Token: Generate a Permanent System User Token in Meta Business Suite → System Users → Generate Token (Required permissions: whatsapp_business_messaging, whatsapp_business_management).
Find in Meta Business Suite → WhatsApp Manager → Overview, or in your App Dashboard URL as waba_id=.... Required for receiving incoming messages via webhook.
In Meta App → WhatsApp → Configuration → Webhook: Enter the Webhook URL above, paste this Verify Token, and subscribe to messages.
Meta Cloud API is Active
You have an active Meta Cloud API configuration. Using WhatsApp Web QR simultaneously may cause message conflicts and delivery issues. Disconnect or remove your API credentials first if you want to switch to QR-based messaging.
Important: QR-Based Messaging Limits
  • New accounts: ~50 messages/day. Established: ~250/day max.
  • Sending too many messages too fast will get your account temporarily or permanently banned by WhatsApp.
  • For bulk/campaign messaging, use Meta Cloud API instead (no banning risk, official support).
